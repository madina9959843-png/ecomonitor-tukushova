# EcoMonitor v1.5 Public

Публичная версия интеллектуального модуля экологического мониторинга атмосферы.

Основные возможности:
- RU / KZ / EN;
- Z-score / IQR / Isolation Forest / Context / R0–R3;
- главная панель, аномалии, карточки событий и аналитика;
- фильтрация по станции, периоду, загрязнителю, категории и уровню;
- публичный read-only режим;
- защищенный вход администратора;
- загрузка CSV только для администратора;
- конфигурация `render.yaml` для публикации на Render.

Подробная инструкция: `DEPLOY_RENDER_RU.md`.
