# EcoMonitor v1.5 — публикация на Render

Эта версия подготовлена для публичного доступа через интернет.

## Что уже настроено

- Публичный просмотр страниц, графиков, фильтров, событий и аналитики.
- Загрузка CSV и сброс базы закрыты для обычных посетителей.
- Администратор входит по паролю.
- Пароль не хранится в исходном коде.
- Сессия администратора хранится в защищенной HttpOnly-cookie.
- Для Render добавлен `render.yaml`.
- После перезапуска Render восстанавливается встроенный демонстрационный набор.
- RU / KZ / EN сохранены.

## 1. Загрузить проект на GitHub

Создайте новый репозиторий, например:

`ecomonitor-tukushova`

Загрузите в корень репозитория ВСЕ файлы и папки этого проекта. В корне должны быть видны:

- `app.py`
- `analysis.py`
- `requirements.txt`
- `render.yaml`
- `static/`
- `data/`

Не загружайте ZIP как единственный файл — Render должен видеть содержимое проекта.

## 2. Создать сервис на Render

В Render выберите создание Blueprint из Git-репозитория. Render прочитает `render.yaml` автоматически.

При создании вас попросят заполнить секрет:

`ECOMONITOR_ADMIN_PASSWORD`

Введите свой пароль администратора. Не публикуйте его в GitHub.

`ECOMONITOR_SESSION_SECRET` Render создаст автоматически.

## 3. После Deploy

Render выдаст публичный URL примерно такого вида:

`https://ecomonitor-tukushova.onrender.com`

Его сможет открыть любой человек.

Публичные посетители могут:

- смотреть главную страницу;
- пользоваться фильтрами;
- смотреть аномалии;
- открывать карточки событий;
- смотреть аналитику;
- экспортировать публичные аналитические результаты.

Публичные посетители НЕ могут:

- загрузить новый CSV;
- сбросить базу;
- заменить демонстрационный набор.

## 4. Вход администратора

На сайте нажмите `Вход администратора` и введите пароль, который указали в Render как `ECOMONITOR_ADMIN_PASSWORD`.

После входа появятся:

- выбор CSV;
- загрузка CSV;
- восстановление демонстрационных данных.

## 5. Важно о данных

В этой версии SQLite используется как временное хранилище публичной демонстрации. На Render база размещается в `/tmp`, поэтому при перезапуске сервиса она восстанавливается из встроенного демонстрационного CSV.

Это специально сделано для безопасной демонстрации: посетители не могут навсегда изменить данные.

Для постоянного хранения пользовательских данных следующая версия должна использовать PostgreSQL.

## Локальный запуск

Обычный публичный просмотр работает без пароля администратора:

```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app:app --reload
```

Чтобы локально проверить админ-режим в CMD:

```cmd
set ECOMONITOR_ADMIN_PASSWORD=МойСложныйПароль
set ECOMONITOR_SESSION_SECRET=локальный-секрет-для-теста
python -m uvicorn app:app --reload
```

Открыть:

`http://127.0.0.1:8000`
